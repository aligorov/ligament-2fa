Единый контейнер (Distroless Docker)
Приложение скомпилировано в единый статический бинарник на Go 1.27 (`CGO_ENABLED=0`) и упаковано в образ `gcr.io/distroless/static-debian12:nonroot`. В контейнере полностью отсутствуют командная оболочка (shell), утилиты и лишние библиотеки, что исключает возможность закрепления злоумышленников.
Надёжное хранилище PostgreSQL
Все данные (пользователи, сессии, токены, журнал аудита, настройки) персистируются в реляционной СУБД PostgreSQL. Приложение автоматически накатывает версионированные SQL-миграции с advisory locks, поддерживает репликацию и стандартные процедуры резервного копирования.

Passkeys / WebAuthn (FIDO2)
Вход без ввода паролей: биометрия Face ID, Touch ID, Windows Hello, а также аппаратные ключи YubiKey. Защита от фишинга на аппаратном уровне и поддержка автозаполнения (Conditional UI).
FIDO2 Level 3 Touch/Face ID YubiKey
Интерактивный Telegram Push & OTP
Собственный Telegram-бот отправляет интерактивные Push-уведомления с кнопками «Подтвердить / Отклонить». Никаких платных SMS: подтверждение входа в Web, VPN и Wi-Fi в один клик.
Push в 1 клик Telegram OTP 0 ₽ за сообщения
TOTP (Google Auth, Яндекс Ключ)
Классические 6-значные коды по стандарту RFC 6238. Генерация QR-кодов происходит прямо в браузере (без обращения к Google Charts API). Защита от повторного использования кодов.
RFC 6238 Google Authenticator 2FAS
Российские SMS-шлюзы & Webhook
Готовые встроенные пресеты интеграции с ведущими операторами: SMS.ru, SMS Aero, SMSC, Простор. Возможность подключения любого корпоративного шлюза через настраиваемый HTTP Webhook.
Резервные коды (Backup Codes)
Пакет одноразовых 8-значных аварийных кодов доступа для сотрудников. Коды сохраняются в базе данных исключительно в виде криптографических SHA-256 хешей с защитой от компрометации.

EAP-PEAPv0 & MSCHAPv2
Собственная реализация EAP state machine и TLS-туннелирования в ядре Go. Позволяет сотрудникам подключать Windows, macOS, Android и iOS к корпоративному Wi-Fi по доменным учетным записям без необходимости выпуска клиентских сертификатов на каждое устройство.
Динамический VLAN (RFC 2868 / 3580)
Автоматическое назначение изолированного VLAN при подключении. Инженер попадает в VLAN 10 (DevOps), бухгалтер — в VLAN 20 (Финансы), гости — в гостевой сегмент. Полная совместимость с UniFi, Cisco, MikroTik, Aruba на основе групп Active Directory.
2FA Push при входе в Wi-Fi
Уникальная возможность: при подключении ноутбука к корпоративной Wi-Fi сети RADIUS-сервер приостанавливает сессию и присылает Push-запрос в Telegram сотрудника. Доступ к локальной сети открывается только после нажатия кнопки «Разрешить».
Поддерживаемое оборудование: Ubiquiti UniFi, Cisco Catalyst / Meraki, MikroTik RouterOS, Aruba, Huawei, Eltex, OpenVPN, WireGuard, WirenBoard

Синхронизация с Active Directory / LDAP
Ligament 2FA интегрируется с Microsoft Active Directory, Samba DC или FreeIPA. Проверка первичного пароля делегируется домен-контроллеру, а группы безопасности автоматически транслируются в роли Ligament и сетевые VLAN. Администраторам не нужно заводить пользователей вручную.
Microsoft Active Directory OpenLDAP FreeIPA Group Mapping
Встроенный OpenID Connect (OIDC 1.0) IdP
Сервер выступает эталонным Identity Provider. Поддержка стандарта Authorization Code Flow с обязательным PKCE (S256), Discovery endpoint (`/.well-known/openid-configuration`), JWKS ротация ключей и выдача стандартизированных токенов доступа.
OIDC Core 1.0 PKCE S256 JWKS Endpoint ID Tokens

Argon2id & AES-256-GCM
Хеширование паролей по стандарту RFC 9106 Argon2id (64 MiB RAM, устойчивость к ASIC/GPU перебору). Секреты и токены шифруются AES-256-GCM с криптографической привязкой контекста (AAD).
Встроенный Fail2ban & WAF
Автоматический подсчет аномалий и мгновенная блокировка IP-адресов нарушителей в БД. Защищает не только Web-интерфейс, но и сетевые порты RADIUS (1812/1813 UDP) от подбора кредов.
Автоматический ACME (Let's Encrypt)
Встроенный HTTP-01 ACME клиент. Сервер самостоятельно получает, устанавливает и пролонгирует доверенные SSL/TLS сертификаты без необходимости разворачивать внешний Nginx или Certbot.
Строгие Web-заголовки и Zero-XSS
Политика Content Security Policy (CSP) блокирует любые внешние скрипты (`default-src 'self'`). Куки защищены флагами `HttpOnly`, `SameSite=Strict`, `Secure`. Все изменяющие действия требуют валидации CSRF-токенов.
Тотальный аудит действий (Audit Log)
Каждое событие (успешный вход, сбой пароля, подтверждение в Telegram, смена прав администратором, выпуск лицензии) регистрируется в неизменяемом журнале аудита с фиксацией IP, устройства и таймстемпа.
