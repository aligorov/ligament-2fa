# twofa

Автономный сервер двухфакторной аутентификации на Go: RADIUS-сервер для RouterOS (pptp/l2tp/pppoe), REST API для управления пользователями и токенами (TOTP), веб-интерфейс и хранение данных в PostgreSQL.

Спецификация: [docs/superpowers/specs/2026-09-05-twofa-server-design.md](docs/superpowers/specs/2026-09-05-twofa-server-design.md)
